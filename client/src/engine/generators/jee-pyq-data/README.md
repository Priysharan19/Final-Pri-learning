# Pri Learning · JEE 41-Year PYQ archive

Generated from the project-owner-provided **Arihant 41 Years IIT JEE Mathematics** PDF.

- 2,242 printed question entries indexed: the chapterwise archive plus the final 2019 JEE Advanced solved paper.
- Pri difficulty calibration: D1 87, D2 645, D3 795, D4 715.
- JEE Main: 637; JEE Advanced / historical IIT-JEE: 1,605.
- Answer modes: 1,296 single-choice, 168 multiple-choice, 149 numeric and 629 source-solution self-check records.
- Every record has a worked-solution step sequence. PriExplainV5 consumes the existing `steps` contract to build the animated worked-solution timeline.
- Five irregular source layouts required a Pri Learning reconstruction from the surrounding printed evidence; those records are explicitly tagged in archive metadata.

The `.b64` files are gzip-compressed UTF-8 JSON encoded as base64. They are partitioned by subject family and lazy-loaded so ordinary Pri question banks do not pay the archive cost.

Do not hand-edit generated question data. Regenerate from the verified extraction/audit pipeline when the source edition changes.
