# Generated web bundle — not tracked

This folder holds the built Pri Learning web application that the native
shell serves over `prilearning://app/`. It is **generated**, never edited and
never committed: every file beside this README is ignored by git
(see `.gitignore` at the repository root, decision D28 of 1 November 2026).

The folder itself must exist because `Package.swift` declares
`.copy("Resources/Web")`; this README keeps it in git so the package resolves
in Xcode and Swift Playgrounds before the first sync.

Generate it from the repository root, in this order:

```bash
npm ci --prefix client     # once
npm run build              # client/dist with release.json and features.json
npm run sync:ios           # copies client/dist into both packages
npm run check:ios          # fails unless each bundle is a complete copy of the build
```

Then press Run in Xcode or Swift Playgrounds. Repeat the three `npm run`
commands after any change under `client/`. CI, the Native Ink lane, the App
Health agent and the release-candidate workflow all run the same three
commands before any Swift step, so no bundle is ever read from git.

Why it left git: Vite gives every asset a content hash, so each client build
renamed about 150 files in two mirrors and every client merge conflicted every
open client pull request on generated bytes. `scripts/resolve-generated-conflicts.sh`
clears those conflicts in a branch that still tracks the old files.
