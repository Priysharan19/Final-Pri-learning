**How merge trains work.** A `task/merge-train-YYYYMMDD-N` branch merges the head of each reviewed PR with `--no-ff`. iOS web bundles are rebuilt once, the full suites run locally, and then the train itself goes through CI. The train merges with a merge commit, and GitHub marks every component PR as merged. Cross-owner governed edits are allowed on `task/` branches. The fleet guard refuses them on `agent/mission/*` branches.
