## Product decision and mathematical proof boundary

- `server/platform/practice.js` alone computes the existing `marksEarned`, `marksPossible` and `creditedMarks` from deterministic marking and the hint ladder. Task 02 only adds `markRows` on the **committed resolved** response. Its read-only serializer `server/platform/markRows.js` cannot award credit, split credit by rubric row or alter persistence.
- A wrong final answer can have actual deterministic aggregate method credit (the original `partial.awarded`). That does **not** establish which authored rubric row earned it. A correct final answer earns the server's full question mark but does **not** certify that every handwritten line was verified. The displayed breakdown deliberately makes **no line-by-line award**.
- `client/src/components/verifiedMarkRows.js` refuses unknown, corrupt, unmatched, stale, unresolved and unverified presentations; the authoritative numerical grade remains separate (`attestedGrade`). Hint-reduced credited marks have a distinct label. No official CBSE marking scheme claim.
- Under the real isolated server in a mounted browser, the fixed-seed Class 10 elimination regression (`c10-linear-pair-methods`, D2, seed 7) verifies an **unmodified deterministic 1/2 mark** for genuine elimination working with a wrong final answer. The same question consumes its first unresolved try without disclosing method marks; a hint reduces credited-account marks without changing the 1/2 award. Only **negative browser network probes** mutate optional response metadata, and are labelled synthetic. No handwriting provider or physical-device evidence.
- The seed is enabled *only* by `onlinePlatform({ allowSeededPractice: true })` in the standalone regression's isolated test process; normal test platform and production refuse client-provided seeds (`PRACTICE_SEED_NOT_ALLOWED`). `e2e.mjs` disables service workers only for flows opting into `inspectNetwork` so browser route interceptions work consistently in Chromium and WebKit. Other browser flows keep normal SW behavior.
