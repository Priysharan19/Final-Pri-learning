# Differentiate a polynomial by the power rule

Course: Year 11 Mathematics Advanced. Type id: `y11-diff-power-rule`. Total: 2 marks.

## Question form

A power or a polynomial is given and the student writes its derivative.

Generator families: `y11-diff`.

## Sample questions

1. Differentiate $y = -8x^{9}$.
   Key: -72x^8

2. Differentiate $y = -3x^{5}$.
   Key: -15x^4

3. Differentiate $y = -8x^{7}$.
   Key: -56x^6

## Criteria

| Criterion | Marks | How the engine decides it |
|---|---:|---|
| Writes a correct derivative. | 1 | a line the step check ticks against the question's derivative step (a line that only restates the function does not count) |
| Gives the final answer correctly. | 1 | the answer checker marks the final answer, the same check that marks a one-line answer |

Total: 2 marks. The marks per criterion are a first guess for the author to correct.

## What the engine can and cannot verify for this type

The page is the marked page the student sees: each line of working is ticked, crossed or left unchecked by the checker. The answer checker is the code that marks a final answer. The server pays exactly the criteria below, from exactly that page.

It can verify:

- Writes a correct derivative.
- Gives the final answer correctly.

It cannot verify:

- It cannot tell a rule line from the final line, so one correct line can earn both criteria.
- It does not check each term separately.

Rule used in every award below: a line earns a criterion only if the marked page ticks it. A line the page crosses, and every line after it, earns nothing. A correct final answer is the full mark, as it always was. A wrong final answer can never reach full marks.
