## Founder contribution verification checklist

The founder verification should specify:

- exact title: Founder or Co-Founder — choose the factually correct one and use it consistently
- start date
- scope of responsibility
- projects/features personally led
- people or partners coordinated
- measurable outputs
- dated records supporting the work
- verifier name, role, email/phone, signature and date

## Evidence quality hierarchy

Prefer, in order:

1. official school/competition/partner documentation
2. independently signed reference or verification letter
3. product analytics / repository / dated system records
4. contemporaneous project records
5. self-authored descriptions only as context, never as sole proof of a major claim
