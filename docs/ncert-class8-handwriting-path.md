# Handwriting path

Numeric Chapters 3–13 practice uses the same production answer path as the rest of Pri Learning: InkAnswer handwriting recognition, confidence handling, marking, retry feedback and Pri Explain. No chapter-specific handwriting recognizer or marker is introduced by this release.

Evidence status: this shared path carries the same evidence boundary as the rest of the handwriting system (`handwriting/v12/PRODUCTION_STANDARD.md`, "Current evidence boundary"). No Class 8-specific real-handwriting accuracy has been measured; the committed real-ink corpus is one writer on the train split, there is no physical-iPad evidence, and the cloud reader is unmeasured. The strict release gates for this path run only in `.github/workflows/release-candidate.yml`.
