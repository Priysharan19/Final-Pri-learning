## Interpretation rule

Probability ranges in this directory are planning estimates, not official acceptance rates. Where a program publishes a real historical denominator, the dossier distinguishes that base rate from the Pri-specific estimate.

Do not treat cloud credits as cash. Do not treat a stale “Apply Now” button as proof that a government scheme is open. Recheck the official source immediately before every application.

## Product-evidence rule

Funding claims must stay inside the repository’s evidence boundary. Software tests and product completeness do not prove educational efficacy. Any claim that Pri improves learning, retention or transfer must be supported by an external study/pilot with an auditable method.

## Update cadence

Update this directory whenever:
- a deadline/status changes;
- Pri submits an application;
- Pri receives a decision;
- external user/revenue/pilot evidence materially changes the probability model;
- company/entity structure changes eligibility;
- a new major funding route is discovered.

Add newer dated files rather than silently rewriting historical snapshots where preserving the old decision record matters.
