## Research stopping rule

For any topic:

Stop broad literature search when additional sources are unlikely to change:
- architecture;
- safety boundary;
- measurement;
- prioritization;
- falsifier.

Then collect Pri-specific evidence.

Research loop from now on:

TARGETED QUESTION
-> EXTERNAL EVIDENCE
-> PRI HYPOTHESIS
-> BOUNDED IMPLEMENTATION
-> BENCHMARK/EXPERIMENT
-> DECISION UPDATE.

Do not return to:
MORE FEATURES -> MORE RESEARCH -> MORE FEATURES.
