# Rejected Patterns

These are explicitly rejected by the current research architecture unless materially new evidence is recorded in #176 and the decision is reviewed in #178.

## Product/AI

- Unrestricted generic chatbot as primary learning UI.
- LLM as final mathematical marking judge.
- One frontier model owning curriculum, truth, pedagogy, privacy and assessment.
- Model/provider upgrade deployed merely because vendor claims it is better.
- Self-modifying critical prompts/policies without admission evidence.
- Generated arbitrary HTML/JS treated as a lesson authority.
- “AI companion” retention based on attachment, exclusivity, guilt or secrecy.

## Learner intelligence

- One scalar mastery value as canonical learner truth.
- Unvalidated Q-matrix or prerequisite edge treated as mathematical ground truth.
- Expert/LLM-authored knowledge-component mappings made irreversible or provenance-free.
- Same generator family's numeric variants counted as independent transfer evidence.
- Elo rating or four difficulty rungs described as a calibrated psychometric scale without calibration.
- Predictive AUC/next-response accuracy used as the sole learner-model admission criterion.
- Response speed treated as fluency without rapid-guess/disengagement checks.
- Model uncertainty discarded before pedagogical policy sees the state.
- One universal mastery threshold for all decisions.
- Prediction treated as prescription.
- “Personalization” meaning only easier/harder questions.
- Five cosmetic variants treated as five independent mastery signals.
- Far-transfer claims from near-duplicate items.
- Hard-coded famous forgetting curve treated as validated mathematics memory model.
- Black-box learner risk score without evidence/contestability.

## Tutoring/learning design

- Immediate correctness as the primary tutor objective.
- Full solution after first “I'm stuck” without evidence-based escalation.
- Permanent scaffolding after competence rises.
- Unguided failure or frustration treated as intrinsically productive.
- Random global interleaving instead of targeted discrimination practice.
- “Learning styles” personalization.
- Reflection/confidence prompts everywhere without information value.
- Hint penalties that discourage legitimate help.
- Animation/cueing everywhere because it looks advanced.
- Engagement/time-on-task treated as learning.

## Handwriting/math authority

- Expected-answer-informed handwriting recognition.
- OCR text as the only canonical representation of rich handwritten mathematics.
- Sampling/numerical checks treated as proof.
- Formal proof checker result accepted without verifying formalization.
- Fluent proof-like prose treated as logical validity.
- One canonical worked solution used as full marking authority.
- Group/teacher-assisted success credited as independent mastery.

## Content/assessment

- “Publicly downloadable” interpreted as commercial reuse permission.
- "Unlimited generated questions" treated as unlimited independent psychometric evidence.
- Item information maximized without content balance, exposure or evidence-diversity constraints.
- Same-family holdout used to claim structural transfer.
- Item difficulty/discrimination estimated from sparse data and displayed without uncertainty.
- Vectorizing/retrieving every available textbook without rights review.
- Generated mathematical correctness treated as psychometric validity.
- Difficulty label trusted because an LLM predicted it.
- Random plausible distractors with no error/misconception model.
- Raw machine translation becoming official assessment wording.

## Safety/privacy/access

- Cloud-only learning core.
- Covert webcam/voice emotion or attention surveillance.
- Collecting sensitive demographics “just in case.”
- Parent/guardian live feed of every error, hint and tutor transcript.
- Consent to use Pri interpreted as consent to analytics, research, cloud AI and marketing.
- Accessibility path treated as a weaker/simplified copy of the “real” math experience.
- Accommodation automatically reducing mastery credit.

## Governance/evidence

- Simulation/offline replay presented as learning efficacy.
- Immediate retry success presented as durable learning.
- Voluntary feature users compared with non-users and the difference called a causal treatment effect.
- Classroom-randomized study analyzed as independent question/learner observations without cluster handling.
- Primary outcome changed after inspecting results.
- Missing/abandoned outcomes silently dropped.
- Repeated dashboard peeking with ordinary fixed-horizon significance thresholds.
- Contextual/personalized policy deployed before a strong non-contextual baseline and heterogeneity evidence.
- Off-policy causal estimate reported when logged behavior has no support for the alternative action.
- Bandit reward silently defined as engagement/session completion and called learning.
- Competitor marketing/capability page treated as independent efficacy evidence.
- Observational analytics presented as causal improvement.
- Vendor case study presented as independent superiority evidence.
- Null results discarded.
- A/B tests optimized only for clicks/streaks/session length.
- New research paper immediately overriding deterministic product invariants.
- Endless broad research once additional literature no longer changes a decision.

## Challenge process

If an agent wants to implement a rejected pattern:

1. Identify the rejected item.
2. Provide materially new evidence.
3. State which current decision is challenged.
4. Define a bounded falsifiable experiment.
5. Keep it out of production authority until decision review completes.
