## How to read this

- **FALSE_CREDIT** is the class that matters: a wrong answer the engine marks right. Each confirmed one gets a deterministic regression test in the JS suites and an engine fix on its own R4 branch with an independent review.
- **FALSE_REJECTION** is a right answer refused with no declared form rule to explain it. It is a learner-facing defect but not a credit leak.
- **SYMPY_UNABLE** means the oracle could not decide (unparseable input, a timeout, or a simplification it could neither prove nor disprove). Numerical substitution is used only to disprove equality, never to prove it.
- The oracle's approximation rule is its own, written from the research standard (exact source, rounding rule, tolerance): a decimal written to p places is accepted for a non-integer key when it is within half a unit of the p-th place and within 10⁻⁴ of the key; an authored `tol` replaces it; `requireExact`/`requireFraction` forbid it. Where the engine is stricter (a precision named in the prompt, an exact-value demand) the pair is **POLICY_STRICTER_APPROX**, not a rejection defect.
- `log` is base 10 and `e` is Euler's number in the engine's syntax; the oracle parses them the same way.
