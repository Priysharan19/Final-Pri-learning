# Dream interface research: Leibniz as reference

Status: research / design direction (not yet implemented). 2 Oct 2026.
Visual version with screenshots and mockups: https://claude.ai/artifact/FPtfn4WUWseixZQSFTphkX (private; owner shares access).

Method: live inspection of https://www.leibniz.com.au/ (home, filter, question and answer screens, computed CSS and `:root` tokens), the Pri build served on localhost:3000, `client/src/theme.css`, the practice components, plus Apple Math Notes and Math Academy as secondary references. Progress and Tasks on Leibniz are sign-in/paywall gated and were not observed; statements about them come from their CSS tokens only.

## Summary

1. **Pri already has Leibniz's skeleton.** Greeting + generate bar, icon rail, star/info/scribble rail, numbered hint ladder, Type/Write/Photo modes, floating "next" pill. Structure is not the gap.
2. **The gap is the skin and the restraint.** Leibniz reads like a typeset exam paper. The running Pri build reads like a SaaS dashboard: violet-to-teal gradient buttons with glow, rounded pills, three competing home cards, marketing copy ("The full adaptive potential is on."), and a logo that renders as a "P" tile followed by "ri Learning.".
3. **The dream is not "dark Leibniz".** It is Leibniz's discipline applied to Pri's own identity, which `client/src/theme.css` already describes: a paper notebook where Pri marks the student's handwriting in the margin like a teacher with a copper pencil.

## What makes Leibniz feel the way it does

| # | Decision | Evidence |
|---|---|---|
| 1 | One typeface for prose and maths | `--font-body: "Computer Modern"`; MathJax with matching metrics. Equations don't look pasted in. Biggest single contributor. |
| 2 | Zero corner radius | `border-radius: 0` on every button, panel, chip. |
| 3 | One accent, once per screen | `--accent: beige (#f5f5dc)` only on the primary action (Generate / Submit / Next). |
| 4 | Tactile "keycap" buttons | Secondary buttons use stacked 1–3px bottom shadows; no gradients, no glow. |
| 5 | The question is the page | Centred column; chrome pushed to thin edge rails. |
| 6 | Progressive disclosure | Hints unlock one at a time; filter tabs (Year → Course → Topics → Dot Points → Difficulty → Type) enable sequentially. |
| 7 | Designed mastery vocabulary | `--mastery-struggling #c46a5a`, `below #d4915a`, `expected #c9a86c`, `strong #a8c686`, `unknown`; separate from annotation colours `correct/partial/error`; separate knowledge-graph palette (`--graph-*`). |

Other observed tokens: background `#0a0a0a`, text `#e8e8e8`, borders/surfaces white at 10% / 5% / 2%, H1 48px, UI 14px.

**Do not copy:** dark-only (wrong default for Pencil-on-iPad in daylight); muted text `#666` on `#0a0a0a` ≈ 3.4:1 (fails WCAG AA); "generated by AI and may be inaccurate" as default (Pri should show curriculum provenance like "NCERT Ex 2.2 · Q4"); paywall-first secondary pages; icon-only nav on touch.

## Secondary references

- **Apple Math Notes:** results appear in the student's own handwriting, in place → Pri's feedback should land on the ink, not in a separate panel.
- **Math Academy:** knowledge graph where colour = stability, reviews credit prerequisites → progress as a syllabus map, not a percentage list.
- **A CBSE exam script:** ruled paper, red margin, examiner ticks, step marks (M1/A1) → a visual language students already know.

## Dream spec

One sentence: **Leibniz's restraint, on paper, with the pencil as the hero.** Light paper default; dark mode is the same notebook at night.

| Layer | Dream Pri | Instead of |
|---|---|---|
| Question type | Maths-native serif (Latin Modern / CMU, self-hosted) for question prose and display, sharing metrics with KaTeX | Inter for questions |
| UI type | Inter 12.5–15px for chrome only | Inter everywhere |
| Ground | Paper desk `#f2f0ea`, sheet `#fdfcf9`; ruled lines and copper margin in Write mode | Midnight navy with glow |
| Accent | Flat Pri teal `#0b6e69`, one primary action per screen | Gradients and glow |
| Marking | good / correction (copper) / uncertain (indigo, dashed) / bad (failure only); never colour alone | Red for mistakes |
| Shape | 0–3px radius, hairlines, keycap shadow on secondary buttons | 8–999px pills |
| Density | One 68ch column, tools on edges | Card grids on working screens |
| Motion | Only for meaning (annotation draw-in ≈200ms, hint unlock, loading underline); reduced-motion respected | Decorative transitions |
| Copy | Calm, specific, teacher-like ("−6 + 4 is −2, not +2") | Marketing lines |
| A11y | Muted text ≥ 4.5:1, 44px targets, labelled tablet rail | Low-contrast greys |

### Question screen after marking (most important screen)
- Ticks/crosses in the red margin; wrong step underlined in copper; note in the outside margin.
- Uncertain readings shown with an indigo dashed box and a "tap to confirm" ask. Recognition stays answer-blind (AGENTS.md invariant); this makes that rule visible as trust.
- CBSE step marks in examiner notation ("1 / 3 · M1 ✓ · A0 · A0"), decided by the deterministic engine, never by a model.
- Provenance chip instead of an AI disclaimer.
- After a wrong answer the pill offers "Try a similar one ›".

### Home
One heading, one sentence, one filter bar + Generate. Collapse GoalCard / DiamondTrack / suggestion into one line: "4 / 10 today · 6-day streak · Next review: Rational numbers". Name in plain ink, not gradient text.

### Progress
Prerequisite graph of chapters coloured with an earth-tone mastery scale (kept separate from marking colours), with a "practise next · weak link: Simplifying terms" annotation.
