# Distinct questions per class (India curriculum)

Generated by `node tools/distinct-questions.mjs`: 2000 seeded draws per generator cell, and 25000 for any cell with no repeat in the first 2000; two draws are the same question when the prompt's numbers and the keyed answer (and MCQ options) are the same. Per cell, the bias-corrected Chao1 estimate S + f1(f1−1)/(2(f2+1)) from the keys seen once (f1) and twice (f2); a cell with no repeat even in 25000 draws is a 95% lower bound n²/6 (1.0×10^8), and a class total that includes such a cell is a LOWER BOUND, marked ≥. **Synthetic sampling estimate — not an enumeration, and not evidence that any question is pitched well.**
