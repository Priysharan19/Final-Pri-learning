# Empty practice cells: chapter × difficulty, both editions

Generated by `node tools/empty-practice-cells.mjs`. Do not edit by hand.

**What this is.** For every year, class, track and Senior stream, the chapters that serve no question at a difficulty, read from the functions the product uses: the NSW issued-cell ledger (`engine/nswOffer.js`, generated from `server/platform/nswBanks.js`) and `indiaRequestableDifficulties` (what the India picker and practice route use). `D#` = served; `-` = nothing is served at that level; `out` = outside the track's advertised difficulty window (the picker does not offer it, and a request for it is answered with the nearest served level).

**What this is not.** It does not invent content: an empty cell is reported, not filled. It counts authored, answer-checked forms, not curriculum coverage or question quality, and no student evidence is implied.
