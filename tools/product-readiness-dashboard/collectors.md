# Pri Learning Readiness Evidence Collectors

## Automated collectors

- GitHub Actions → engineering reliability
- Test suites → correctness evidence
- Handwriting benchmarks → recognition evidence
- Curriculum audit scripts → content coverage
- Accessibility tests → UX quality
- Build pipelines → release readiness

## Human validation collectors

Some metrics cannot be generated from code:

- real student usage
- teacher agreement
- classroom outcomes
- handwriting from unseen writers
- competitor feature parity

These remain incomplete until measured.

## Rule

No evidence = incomplete.
A missing metric never becomes a guessed percentage.
