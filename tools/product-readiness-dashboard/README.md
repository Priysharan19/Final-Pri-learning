# Product Readiness Dashboard

This dashboard measures how close Pri Learning is to a production education platform.

It is separate from engineering completion.

## Three layers

1. Engineering Health

Does the software work?

2. Product Maturity

Does the product have the capabilities needed to compete?

3. Market Readiness

Has it been validated by students and teachers?

## Scoring rule

Every percentage must come from evidence.

The system must show:

- evidence item
- pass/fail state
- source
- last validation date
- calculation

No manually typed completion percentages are permitted.
